# svg-path-1 路径交换迁移决策记录

## 背景

历史稿本中的轮廓（形状 `path`、图层 `clip`/`mask`）以 M/L/Q/C/Z 对象数组持久化，机器可读但不便于与矢量工具交换。目标是引入版本化的 SVG 路径文本，同时保留旧请求、快照和封包的读取能力，且不改变任何既有填充与镂空含义。

## 决策

### 解析器：内部手写受限解析器，不引入外部依赖

仓库约束为仅依赖 Go 标准库，且安全边界要求“不接受任意 SVG 标记”。因此在 `internal/geom/svgpath.go` 实现手写词法/语法解析器，而不是引入 XML/SVG 库：

- 语法面被收窄为 path data 文法本身：动词仅 `M/L/Q/C/Z` 与小写相对形式，数值遵循 SVG 数字文法（符号、前导点、小数、科学计数法），分隔符为空白与逗号。
- `H/V/A/S/T` 等动词在词法层即拒绝，`<script>`、样式、外链等标记无法通过纯 path data 入口进入系统；外层 JSON 解码器继续 `DisallowUnknownFields`。
- 解析产物是与历史表示同构的绝对 `[]geom.Op`，随后复用既有的闭合轮廓校验、`geom.Flatten`（Q 固定 16 段、C 固定 24 段）和同一条栅格/矢量管线，不存在第二套几何语义。
- 错误类型 `geom.ParseError` 携带字节偏移与列号，并通过 `errors.As` 穿透 `encoding/json` 包装；结构性错误在 validate 层补充来源节点与表示标签。

### 过渡方式：双表示共存、单向归一化、摘要按归一化内容计算

- `scene.PathRef` 是每个轮廓的唯一入口类型，线格式二选一：历史数组（字段名 `path`/`clip`/`mask` 不变）或 `{"path_format":"svg-path-1","path_text":"..."}`。同时提供或都不提供均为契约错误。
- 解码即归一化为绝对 `[]geom.Op`；来源表示仅作为派生的 provenance（`Source`/`Text`），不参与下游计算。
- 序列化保持提交时的拼写：旧数据往返仍是对象数组，svg-path-1 请求往返仍是版本化文本，不会发生静默格式翻转。
- 稿本摘要 `repository.SceneHash` 先将文档深拷贝归一化为旧数组再哈希，因此同一几何的两种表示共享同一稿本 digest，进而得到相同的 PNG/SVG 成品标识与字节。
- 封包摘要 `bundle.Seal` 保持历史算法（按存储字节哈希），旧封包摘要字节不变；`bundle.Open` 在原始摘要之外额外接受归一化摘要，允许合规工具改写路径文本后的封包通过校验。
- 状态快照 schema 仍为 `prism-plate-v1`：新增字段是同一 schema 下的可选表示，旧二进制写出的 state.json 可直接被新二进制打开并重编译。

### 语义保持的关键约束

- 相对动词的每组坐标相对于该动词组开始时的当前点解析，控制点不移动当前点；多子路径仍要求子路径之间显式 Z，禁止用第二个 M 隐式开环。
- 填充规则 `nonzero`/`evenodd` 仍是形状级独立字段，路径文本不承载也不允许改写它；顶点顺序不被重排，镂空方向含义保持。
- 边界：单条文本 16KiB、操作数 1..256、数值必须有限且落在既有的 `finite` 范围内，超限与 NaN/Infinity 一律拒绝。

## 证据

- 单元测试：`internal/geom/svgpath_test.go`（相对坐标、数值写法、多子路径、曲线、错误列号、填充语义、规范序列化）、`internal/scene/pathref_test.go`（双表示解码、互斥、未知字段拒绝、错误定位穿透、逐层往返）、`internal/repository/digest_test.go`（摘要与表示无关、旧线格式稳定）。
- 端到端：`scripts/path-migration.py` 经真实 HTTP 与临时持久化根验证两种表示的 digest/PNG/SVG 完全一致、相对坐标重渲染一致、拒绝路径带定位、重启后旧快照可读、两类封包往返并重新出图。
- 基线对照：以基线二进制和新二进制分别提交 `examples/amber-proof.json`，稿本 digest、PNG 与 SVG 成品 digest 全部逐字节一致；封包内文档去除时间戳后深度相等。

## 未纳入范围

开放路径、`H/V/A/S/T` 动词、非闭合子路径、任意 SVG 标记与 XML 结构均明确不接受；本次支持范围仍限于已有闭合路径契约。
