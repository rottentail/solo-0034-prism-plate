# 填充规则转换设计

协作方只接受统一的填充规则，但直接把形状的 `fill_rule` 从 nonzero 改成 evenodd（或反向）会改变孔洞与重叠区域的可见性。本设计提供一个只读的改稿候选接口：用户选定目标规则后，服务把**可见填充区域**重写为在目标规则下渲染结果不变的可编辑闭合路径，而不是只替换字段。原稿始终保留，候选经审阅后才通过普通修订流程提交。

## 转换后轮廓如何表达

转换在形状的局部坐标进行，复用 `geom.Flatten` 已有的折线几何（M/L/Q/C/Z → 闭合折线，Q/C 固定 16/24 段），因此输出仍是现有可编辑闭合路径契约：

- 输出仅由 `M`/`L`/`Z` 指令组成，不合成新的曲线动词；含曲线的原稿按共享细分契约展开，并在报告中披露为近似。
- 每个输出环是平面排列（planar arrangement）中填充/空白分界的一条边界，填充区域保持在边界固定一侧，因此外环与孔洞环的绕向天然一致，目标规则下的 winding/parity 与原可见区域相同。
- 形状的 `brush`、`transform`、图层 `clip`/`mask` 以及同层其他形状逐字节保留；只替换目标形状的 `path` 与 `fill_rule`。

## 平面排列与边界提取

1. **顶点吸附与去重**：以坐标跨度派生几何容差 `eps = max(span*1e-9, 1e-7)`，把近重合顶点吸附为同一排列顶点。`dedupRing` 只折叠相邻重复点（零长边）和首尾重合点，保留 8 字轮廓在自交点的合法重复经过。
2. **相交分裂**：固定点迭代地在每对线段（含同一环的两条边，覆盖自交）的交点处插入共享顶点；相切与近重合在容差内吸附，并记录为接触证据。
3. **半边结构**：每条分裂线段建一对孪生半边，顶点出边按极角排序，以"孪生边的前驱"建立面旋转，做带面在右的面游走；非流形（游走不闭合、留下未访问边）直接判定为不可靠输入并拒绝。
4. **面分类与边界环**：对每个面取内部探测点，用渲染器自身的 `geom.Path.Contains` 在源规则下判定填充；填充面与空白面之间的半边构成边界，沿边界游走得到输出环。外部面通过"不在任何环内"识别，且必须被判为空，否则拒绝。
5. **共线清理**：只删除支撑线容差内的直通顶点，保留拐角、T 接与交点，几何不变。

嵌套、相反绕向、相切、自交、多个互不相连的分量都由同一排列机制处理；负行列式（镜像）变换不影响局部坐标下的拓扑，变换原样保留，镜像后的设备坐标结果仍与原稿一致。

## 区域等价如何检验

候选在返回前必须同时通过两类独立证据，任一失败就拒绝、不返回候选：

- **几何证据 1 — 精确填充面积**：在所有顶点 y 与所有交点 y 切出的水平条带内做扫描线积分，按目标规则的 winding（nonzero）或 parity（evenodd）累加填充跨度。条带内无端点，交点 x 随 y 线性变化，对折线几何是精确的。源与候选的面积差必须不超过 `max(eps², 源面积*1e-9)`。
- **几何证据 2 — 点归属网格**：在局部包围盒（外扩 5%）上取 64×64 的确定性低差异抖动网格，落在任意边 `4*eps` 内的点跳过并计数，其余点要求源规则与目标规则的 `Contains` 结果完全一致，`grid_mismatches` 必须为 0。
- **图像证据**：`scripts/fill_convert_evidence.py` 用真实 HTTP 服务在提交候选前后各渲染一张 PNG，自带 PNG 解码器逐通道比较；嵌套、重叠、相反绕向、相切、自交、镜像、带裁域七个场景全部要求字节一致。Go 测试 `internal/convert/raster_equivalence_test.go` 也通过生产渲染管线断言逐像素相同。

面积度量处理了重叠（nonzero 重叠只算一次）、孔洞（相反绕向相减）和自交（8 字按实际两个叶瓣计），不依赖输入环的绕向。

## 不可靠输入如何判断

报告的 `reliability` 分三档：

- `exact`：无接触、无近似，面积与网格全部通过。
- `approx`：出现容差内相切/近重合、最窄通道低于 0.25 设备单位（`min_channel_device_units`，局部宽度经变换最小轴尺度换算）、或原稿含曲线只能按细分折线表达。候选仍给出且通过等价检查，但 `warnings` 与 `approximation_required` 在提交前明确说明。
- 拒绝（不返回候选）：环在容差内塌缩到少于三个顶点、排列非流形、面游走不终止、无法识别外部面、网格出现可见性差异、或候选路径指令超过 256 条的编译准入（`node_budget_blocked`）。窄通道附近若只能近似或超出节点限额，都在提交前以错误或警告说明，绝不静默截断。

候选还会调用与所有 HTTP/恢复场景相同的 `validate.Compile` 准入；不能通过编译的候选不会返回。

## 不可变性与提交

转换接口不写入仓库：调用成功后版面稿本数量、规则与原始路径不变。`candidate_document` 是完整文档，审阅报告后由调用方带 `expected_revision` 走 `PUT` 修订；旧稿本按既有不变量永久保留，冲突仍返回 409。封包导入、恢复重编译、成品摘要等既有流程对新稿本一视同仁。
