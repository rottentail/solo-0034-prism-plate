# 棱版可重排图稿 · 复核依据

本文件是布展现场的复核基准：既用于区分**真接缝缺陷**与**预览采样差异**，也用于判定
何时单砖调整即可、何时必须整体重排。配套：`out/rehang/placement.md`（施工单）、
`out/rehang/report.json`（自动核验报告）、`out/rehang/zooms/`（缝位/交点放大校样）。

## 1. 校样体系与权威性

- **PNG 为像素权威**：每像素 2×2 四点覆盖采样，确定性成像；同一稿本重渲染字节一致
  （report.json 的 `determinism` 已验证：L2 重渲染一致、单砖恢复版与 L2 逐字节一致）。
- **SVG 为矢量校样**：与 PNG 复用同一展开几何；浏览器在覆盖率与透明插值上可能有差异，
  不承诺逐像素相同。SVG 用于任意放大查看曲线与标记形状，不作像素级裁决。
- 本批校样由 `scripts/prismplate_local.py`（prism-plate-v1 契约的离线实现）生成；
  `out/rehang/scenes/*.json` 是标准稿本，有 Go 环境时可原样 POST 棱版服务复现并交叉核对。

## 2. 真接缝 vs 预览采样差异

| 现象 | 判定 | 依据与特征 |
|---|---|---|
| SVG 预览中砖缝有 ≤1px 底色细线 | **采样差异** | 查看器对相邻裁切多边形分别抗锯齿，覆盖互补不重合；沿缝均匀、不随放大扩散、线上无图案错位。以 PNG 同位置为准 |
| PNG 缝位 1px 内轻微混色 | **采样差异** | 四点覆盖采样的子采样点分落缝两侧；特征级断裂（≥2px 错位、色块错序）才是实物问题 |
| 缝两侧底色轻微阶跃 | **正常** | 两类砖本色不同（甲 #fbf8f0 / 乙 #edf3f6）且分砖印刷；阶跃应整齐、沿全缝一致 |
| 边标记不同（双三角对上单菱） | **真缺陷·标记级** | 摆法无效，直接走整体重排 |
| 曲线端点未跨缝、端口错位 | **真缺陷·端口级** | 放大校样中端点应正好过缝且两侧相接 |
| 跨缝曲线出现折角 | **真缺陷·切线级** | 所有曲线以垂直接边设计，跨缝切线必共线；折角说明砖错或砖伤 |
| 缝位光晕两侧墨色与施工单不符 | **真缺陷·叠色级** | 例：缝②应青青成整菱，出现青—品红即错（见演练 fault） |
| 中心交点四象限色序与摆法表不符 | **真缺陷·角部级** | 角序是朝向的最终判据（见演练 fault/swap） |
| 中心章三角朝向/识别色与摆法表不符 | **真缺陷·朝向级** | 每砖唯一识别色，朝向见摆法表 |

一句话：**采样差异沿缝均匀、放大不扩散、不破坏图案连续性；真缺陷集中在特征点
（端口、交点、标记、中心章），任意缩放级别稳定可见。**

## 3. 复核流程（对缝四查 + 一点）

1. **查标记**：每条内缝两侧记号相同（双三角↔双三角、单菱↔单菱）。
2. **查端口**：曲线端点正好跨缝相接（对照 `zooms/` 放大校样）。
3. **查叠色**：缝位光晕拼成完整菱斑，两侧墨色符合施工单「叠色」列。
4. **查角序**：中心交点四象限楔形色序符合摆法表。
5. **查中心章**：每砖三角朝向与识别色符合摆法表。

自动核验：重跑 `python3 scripts/rehang.py`，`report.json` 中两套可用摆法的
`intrinsic_ok` 应全为 `true`，三套演练判定应复现（fault→单砖可恢复、
fixed→与基准一致、swap→需双砖对调）。

## 4. 恢复阶梯：单砖 → 对调 → 整体重排

- **阶梯 1 · 单砖旋转**：标记全对但角序/叠色/朝向不符时，对嫌疑砖最多试 4 个朝向；
  任一朝向使全部检查通过即恢复（演练 fault：T4 原地旋转 180°）。
- **阶梯 2 · 双砖对调**：单砖所有朝向都无法同时满足各缝时，查同型砖是否对调
  （演练 swap：T3↔T4，连位置带朝向整体互换）。
- **阶梯 3 · 整体重排**：出现以下任一情况，按施工单整版重摆，不做局部修补：
  - 任何内缝标记不符（双三角对上单菱）——当前摆法本身无效；
  - 对调后仍有角序/叠色不符；
  - 端口物理对不上（砖面损伤、裁切误差）——不属摆放问题，上报评估，勿用重排掩盖；
  - 与源稿多项不符且无法定位到具体砖。
- 原则：能用单砖不动双砖，能用双砖不做整版；每次调整把结论记入复核记录。

## 5. 本次演练结论（已随交付复现）

| 演练 | 边标记 | 端口/切线 | 角部 | 叠色 | 判定 | 处置 |
|---|---|---|---|---|---|---|
| fault · T4 装反 180° | 全对 | 通过 | 错（SE 象限） | 错（缝②④） | 单砖可恢复 | T4 旋转 180°，恢复版与 L2 逐字节一致 |
| swap · T3↔T4 对调 | 全对 | 通过 | 错（SW/SE 象限） | 错（缝②③④） | 需双砖对调 | T3↔T4 整体换回 |

结论：**边标记配对只是必要条件**——装反的砖可以让标记、端口、切线全部通过；
**角序 + 叠色 + 中心章才是现场判对的充分条件**。三者全对，才允许开展。
