# 运行与恢复

仅暴露在可信网络，默认回环监听。没有账号体系、远程资源加载和数据库服务。二进制支持标准SIGTERM/中断信号，HTTP等待最多40秒，成像最多30秒，随后等待工作者退出再关闭数据根。

容器使用scratch和UID 65532。将可写目录挂到/data并提前给UID65532写入权，单副本使用同一数据根，监听7846。Dockerfile的镜像拉取需要网络；本机独立构建与流程验证不需要Docker。

备份需正常关停后复制state.json。恢复先保留原件，在独立目录启动验证；不要在服务写入时替换state.json。稿本摘要、成品摘要、引用关系和场景准入都会校验。snapshot不包含任务队列，恢复后需要重新提交未形成成品的任务。

writer.lock保存写入进程号。异常退出后确认没有旧写入进程再删除锁；PID本身不能证明跨主机或容器活性。正常关停应自动移除。不能同时启动两台服务共享数据根，不能使用无原子重命名语义的挂载替代文件系统。

原子替换前写入与fsync失败不会改变服务事实；替换是提交点，目录fsync采用尽力执行，因此突然断电后的目录持久性受宿主文件系统保证影响。不能把此行为描述为跨文件事务或多机强一致。

容量告警由HTTP拒绝和错误文本提供，当前没有指标采集、自动清理、压缩或归档搬迁。256条瞬态任务记录用尽需正常重启，成品不受影响。预计大场景应先评估1.6亿逐采样可见边遍历预算；同步与异步共享两个计算名额。

预算只对可能覆盖采样点的几何收费：形状轮廓先在局部坐标取含全部环（镂空内环计入并集，不会缩小包围盒）的包围盒，再经声明的仿射变换做四角精确映射；变换后的盒子与带1e-9+1e-12·坐标量级安全间距的画布严格分离时，该几何判定为不可见，既不进入可见边预算，也被PNG光栅器逐采样跳过。接触或擦过画布边界的几何因间距保持可见，不会被粗略裁掉；同一形状路径内只要有一个环与画布相交，整条路径按填充规则逐环参与逐采样判定并全额计费。不可见轮廓仍要展开和随SVG导出，因此另设350万条展开边上限约束一次性工作。建版、修订、封包导入（bundle.Open）、启动重编译和每次出图都调用同一编译入口，准入结论对同一稿本完全一致。

部署后先运行healthz，再使用演示输入生成PNG/SVG并获取成品摘要；随后正常关停、重启核对同一成品。容器镜像验证、跨架构验证、压力测试与故障注入需要独立证据，本初始化不将它们宣称为已通过。
