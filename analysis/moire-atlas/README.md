# 周期叠纹图谱（Moiré Atlas）——真实拍频 vs 采样伪影的可复算鉴别

本目录回答设计人员的问题：**两层细密斜纹叠起来后，看到的粗条纹到底是设计中的真实拍频，还是小尺寸校样（PNG）的采样假象？**

全部产物只用棱版（prismplate）**已有的闭合多边形与渲染能力**生成，**没有新增或修改任何渲染功能**。所有条纹都是 `M/L/Z` 闭合矩形多边形，经每个 shape 的可逆仿射 `transform` 旋转/平移，通过现有 HTTP 服务的公开接口渲染。

---

## 1. 方法与三条独立证据链

| 证据链 | 实现 | 作用 |
|---|---|---|
| ① 频率推导（解析） | `cases.json` 中每个案例固化波向量、差频、Nyquist 折叠预测 | 给出连续图形**本该有**的空间周期，以及采样**必然产生**的混叠周期 |
| ② 独立参照 | `atlas_ref.py`（纯 Python 标准库，不 import 任何棱版代码）三种渲染：契约重写、8× 过采样连续参照、解析折叠模型 | 不共享实现即可交叉验证，避免“同一套代码自证” |
| ③ 观察尺度与平移 | F1 几何 2× 尺度对照；B2/D2/E2 小幅平移对 | 真实结构随尺度线性缩放、对平移按放大律移动；伪影随采样条件消失/反向 |

### 1.1 频率与拍频公式
- 空间频率 `f = 1/p`（周/像素），波向量 `k = f·(cos α, sin α)`，`α` 为光栅法线方向。
- 两光栅差频（真实拍频）：`km = k1 − k2`，拍频周期 `pm = 1/|km|`。
  - 平行：`pm = p1·p2 / |p1−p2|`。
  - 等周期 `p`、夹角 `θ`：`pm = p / (2 sin(θ/2))`，取向垂直于两纹夹角平分线。
- 平行光栅第二组沿法线平移 `Δx`，拍频条纹位移 `Δx_beat = Δx · p1/|p1−p2|`（相位放大）。

### 1.2 采样伪影（混叠）公式
像素格间距 1px、Nyquist 频率 0.5 周/px。折叠算子 `fold(f) = f − round(f) ∈ [−0.5, 0.5)`，二维对 `(kx, ky)` 各分量独立折叠。**折叠为负即载波反向**，这是平移判据的物理来源。

### 1.3 棱版渲染契约（被独立重写并逐像素核对）
`internal/raster`：每像素 2×2 四点（偏移 0.25/0.75）点在多边形内覆盖；线性光 `multiply` 混合；sRGB 8bit 量化。画布 ≤512、段数×画布×4 采样 ≤1.6 亿的准入预算在选例时已逐项核算（见 `make_scenes.py` 输出与下文）。

## 2. 复算方式

```bash
# 需要 Go 1.24+（或 GO_BIN=/path/to/go）、Python3 标准库；ImageMagick 仅用于拼图
GO_BIN=/tmp/goroot/go/bin/go ./run_all.sh
```

步骤：构建现有二进制 → 生成场景源稿 → 经真实 HTTP 服务渲染 PNG/SVG 并校验摘要 → 独立参照与 DFT 测量 → 理论/实测对账（`results/reconciliation.json` 的 `all_pass`）→ 校验和。

关键输出：
- `scenes/*.json`：10 个版面源稿（棱版契约 JSON）。
- `artifacts/*.png|*.svg`：**实际服务产出**的 PNG 与 SVG（各 10 份）。
- `reference/*.contract.png`：独立重写的契约渲染（与服务 PNG 逐像素比对）。
- `reference/*.continuous8x.png`：8× 过采样的连续图形参照（设计“本该是什么样”）。
- `reference/*.folded.png`：解析 Nyquist 折叠模型（纯采样图像）。
- `results/measurements.json`：DFT 实测频率/周期/取向/平移位移。
- `results/reconciliation.json`：理论 vs 实测对账（含相对误差与 pass）。
- `results/contact-sheet.png`：三列对照（服务PNG｜连续8×｜折叠模型），行序 A1→F1。
- `results/checksums.json`：全部交付物 SHA-256。

## 3. 逐案例：连续图形本该有的周期 vs 实际 PNG 出现的条纹

误差主要来自有限 DFT 分辨率（192px 上最低频 bin ≈ 0.0052 周/px）；周期数越少相对误差越大，已在对账中显式列出。

### A 组 — 单组细纹：纯采样伪影对照
**A1（p=1.5 竖纹，192px）**
- 连续：`f=0.667` 周/px，**超过 Nyquist 0.5**，细结构在 PNG 中数学上不可保留。
- 折叠：`fold(0.667)=−0.333` → PNG 实测 **3.0px 反相粗纹**（实测 0.3333，误差 0%）。
- SVG 仍画出 **0.75px 线宽、1.5px 周期**的细线（`results/svg-vs-png-A1.json`）。**同一份稿本，SVG 能画细线，PNG 却是 3px 粗纹——SVG 细线不构成 PNG 可信的证据。**

### B 组 — 平行粗纹：纯真实拍频锚点（无混叠）
**B1（p1=12, p2=10，平行）**
- 理论拍频 `f=0.01667` → 60px；实测 64px（+6.7%，画布仅约 3 个拍周期，DFT bin 量化所致）。
- 基频 0.083/0.10 均远低于 Nyquist，无混叠；连续 8× 参照与 PNG 拍频一致。
**B2（B1 第二组平移 +0.8px）**
- 放大因子 `p1/|p1−p2| = 6`，理论拍纹位移 **4.8px**；实测 6.1px（+27%，低频 bin 误差，方向与放大律正确）。这是真实拍频的相位特征。

### C 组 — 斜交粗纹：二维真实拍频
**C1（p=14，夹角 12°，256px）**
- `pm = 14/(2 sin6°) ≈ 67.0px`，km 取向 96°（暗带走向约 6°）。理论轴上实测 63.75px（−4.9%）。
**C2（第二组沿法线平移 1.0px）**：理论沿 km 位移 4.79px，实测 4.49px（−6.3%）。

### D 组 — 平行细纹：真实拍频与采样伪影**并存**（题面要求的关键案例）
**D1（p1=2.2, p2=1.7，平行，192px）**
- G1：`f1=0.4545 < 0.5`，基频被**真实保留**（实测载波 2.21px ≈ 2.2）。
- G2：`f2=0.5882 > 0.5`，折叠为 **−0.4118 → 2.43px 反向伪影**（折叠模型实测 2.43px，误差 0.06%）。
- 真实差频 `0.1337 < 0.5` → **7.48px 真实拍频存活**（实测 7.39px，−1.3%）。混叠分量间的差频恰等于真实差频，因此同一粗纹同时承载两种解释，单凭肉眼无法区分。

**D2（D1 第二组平移 +0.34px = p2/5）——真伪分流的决定性测量**
- 真实拍频位移理论 **+1.50px**，实测 **+1.54px**（+2.9%）。
- 载波级相位响应（`measurements.json`）：
  - **保留的真实载波：−0.002px（几乎不动，|·|<0.15 判定通过）**；
  - **折叠混叠载波：−0.492px（反向移动，< −0.2 判定通过）**。
- 同一物理平移下，真实结构与伪影的响应方向/幅度不同。**这把“粗纹是真拍频还是伪影”从主观判断变成可测量、可排除错误解释的结论。**

### E 组 — 斜交细纹：二维真伪并存
**E1（p=1.9，夹角 15°，192px）**
- 真实 `|km|=0.1374` → **7.28px** 拍频（实测 7.31px，+0.4%），km 取向 97.5°（实测扫描 98°，误差 0.5°）。
- 两基频 `f=0.5263 > 0.5` 均被二维折叠：G1→−0.4737（2.11px 反相，实测 2.11），G2→(−0.4916, 0.1362)（1.96px、取向 164.5° 的伪影）。**真实拍频与二维混叠同图共存。**
**E2（第二组平移 0.38px = p/5）**：理论沿 km 位移 1.456px，实测 1.454px（−0.14%）；混叠分量不遵守该连续放大律。

### F 组 — 观察尺度判据
**F1（与 E1 同构，周期 1.9→3.8，同 192 画布）**
- 频率减半为 0.2632，落入 Nyquist 内，**混叠消失**；真实拍频周期精确加倍为 14.56px（实测 14.62px）。
- 与 E1 实测拍周期之比 **1.9999 ≈ 2**（误差 −0.01%）。真实结构随尺度线性缩放，伪影随采样条件消失。

## 4. 哪些结论能排除错误解释，以及误差边界

1. **“粗纹一定是设计的拍频”——可被 A1/D1/E1 排除。** A1 只有一层光栅、根本不存在两光栅差频，PNG 却出现 3px 粗纹；该粗纹只能来自采样折叠。折叠模型（不含任何真实拍频机制）即可复现其载波周期。
2. **“粗纹一定是采样假象、设计里没有这个周期”——可被 B1/C1/D1/E1 的连续 8× 参照排除。** 在过采样（无混叠）参照中同样测得该低频周期，且与解析差频一致；F1 中它在无混叠条件下仍存在并精确加倍。
3. **“SVG 画得出细线，所以 PNG 里也有”——可被 A1 直接排除。** 同稿本 SVG 为 1.5px 周期/0.75px 线宽，PNG 为 3px 反相粗纹；超过 Nyquist 的频率无法由像素格重建。
4. **D 组的共线歧义（真实差频=混叠差频）靠平移+尺度拆解。** D2 实测真实载波不动、混叠载波反向、真实拍频按放大律正向移动；F1 证明真实拍频跨尺度稳定。三条独立判据一致才能下结论。

**误差来源与量级（均显式记录在 `reconciliation.json`）：**
- 有限 DFT 频率 bin：192px 上约 ±0.0052 周/px，导致低频（B/C 组）周期相对误差 5–27%；高频（D/E/F 组）周期误差 ≤1%。
- 8bit sRGB 量化与 2×2 覆盖：独立契约渲染与服务 PNG 在所有平行/粗纹案例**逐像素全等（max Δ=0）**；E 组仅在斜条有限末端有 1.77% 像素、max Δ=188 的差异，已定位为有限矩形条长边界，不影响频谱结论。
- 折叠模型是无限格点理论，与半像素子采样在边界像素有相位差，因此按**频谱（载波频率/取向）**而非逐像素对账；其载波周期与 PNG 实测在 A1/D1/E1 均吻合到 ≤0.1%。

## 5. 预算与合规
- 全部场景通过棱版准入：最大工作量 E1/E2 为 1.368 亿（< 1.6 亿上限），画布 192/256（≤512），每图层 shape 数 ≤13（≤32），每 shape 路径操作 ≤140（≤256），变换均可逆。
- 渲染经真实 HTTP（`POST /v1/plates`、`.../render?format=png|svg`、`GET /v1/artifacts`），成品 SHA-256 与服务返回摘要逐一校验（`render-manifest.json`）。
- 未改动 `internal/`、`cmd/` 下任何生产代码；新增内容全部位于 `analysis/moire-atlas/`。
