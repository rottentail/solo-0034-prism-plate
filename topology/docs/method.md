# 区域与拓扑推导方法

## 1. 被分析的对象

产品（`internal/geom.Flatten`）把每条 Q/C 以固定 16/24 步采样为折线，`internal/raster` 对每个采样点以其形状的逆变换回到局部坐标，再用形状声明的`fill_rule` 判定。因此“被绘制的填充集”是：

> 每个形状：`M_s( {q : fill(local_path_s, q, rule_s)} )` 的并集，其中 `M_s` 是该形状的仿射矩阵。

本册所有形体都是不透明实色（alpha = 1）、图层 opacity = 1、图层 blend = normal，所以逐形状的“先画后画”在拓扑上就是并集；若改用半透明叠色，应把判定对象改成每种颜色的可视区域，而不是并集。

本册的拓扑结论都针对这个折线集合，而不是 PNG 像素。PNG 是覆盖采样结果，只用于校样；像素连通性受抗锯齿、4 点覆盖和 4/8 邻接约定影响。

## 2. 有向面积：曲线精确值

对每段多项式曲线直接用 Green 定理 `A = ½∮(x dy − y dx)` 做精确有理积分：

- 直线段 `(x₀y₁ − y₀x₁)/2`；
- 二次/三次段把 `x(t), y(t)` 展开为幂基，`∫(x y′ − y x′)dt` 逐项积分；
- 全程使用 `Fraction`，没有浮点误差。

对 `k=2/3` 控制点的三次椭圆，精确面积是 `10/3·a·b`；本册 C 组的所有椭圆都用这一族，因此“椭圆复合轮廓的有向面积”可以手算核对（例如 C1 = 20160 − 2640 = 17520）。

## 3. 区域：精确竖向条带排列

1. 用折线（16/24 契约）作为边界，按所有顶点 x 坐标把平面切成开条带；
2. 条带内边是线性的，按竖直次序排序，相邻两条边之间是一个开单元；
3. 每个开通/闭单元用精确有理点做绕数或奇偶判定（`nonzero` / `evenodd`）；
4. 相邻条带的单元按共享竖线上的重叠区间连接：正长度重叠 → 连通；只共享端点 → 仅在闭包读法下连通；
5. 单元面积用梯形公式精确求和。

独立校验（`tools/selfcheck.py`）：

- 面恒等式：`Σ (绕数 × 面积) = 折线有向面积`，单形状全册成立；
- 扫描线：用完全不同的水平扫描 + 绕数中点判定重算填充面积，与排列结果一致；
- 细分收敛：折线有向面积随 8/12 → 16/24 → 32/48 → 64/96 单调逼近曲线精确值。

## 4. 孔与连通块：两种接触约定

填充集是路径定义的开集，因此“开”读法是规范答案：

- 连通块 = 填充开集的连通分量；
- 孔 = 有界、且与填充块共享正长度边界的未填充开分量（外部无界分量不计）。

“闭”读法（点接触也连、共边也连）对应 8 邻接栅格与人眼的直观。两者不同时，说明结论只在“接触点是否算同一块”这一自由度下成立——本册把它标为 `determined-with-contact`，并把接触点逐点列出。

## 5. 曲线近似到什么程度

对每段曲线给出弦误差上界：C² 曲线在一段参数区间长度 `1/n` 内，弦与曲线距离 ≤ `(1/8)(1/n)² max|B″|`；二次 `B″=2(P₀−2P₁+P₂)`，三次 `B″=6((1−t)d₀+t d₁)`。本册 16/24 契约下界为 0.02–0.06 个画布单位。

要支撑拓扑判断，还需要把真实曲线与折线的关系证书化：

- **分离证书**：对两条曲线的控制点盒做精确分支定界；若每对盒的距离都 > 2b，真实曲线相距 > 2b，折线不可能改变相交结构；
- **相交证书**：在真实曲线上取有理参数点 p，若 p 到折线的距离 > b，则 p 对真实曲线与折线的绕数相同；若沿曲线取到两个不同绕数的点，真实曲线必然穿越；
- **相切证书**：共享的精确端点就是真实公共点；其余部分若被 2b 分离，则相切只发生在该点。

C3（间隙 ≈ 1e-4 ≪ b）无法通过：真实曲线被证明分离，但间距小于 2b，折线相交而曲线不相交，因此其折线拓扑不能当作曲线拓扑，判为未定。

## 6. 仍保留未定的情形

- 间距小于 2b 的近切（C3）；
- 折线本身在细分之间改变计数（本册未出现，但检测器会报告）；
- 需要“曲线相切但未共享端点”的精确切点（本册只用共享端点或近切，不猜切点）。

除此之外的案例，开集计数是精确的；接触自由度单独标注，不混入“有向面积”。
